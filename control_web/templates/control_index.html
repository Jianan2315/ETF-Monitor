交易时段防休眠

工作日按设定时段阻止电脑因空闲自动休眠。显示器仍可关闭，时段结束后恢复原有电源策略。

该功能使用 Windows 任务计划程序。电脑处于睡眠状态时会请求在开始时间唤醒； 完全关机时无法自动开机，合盖休眠也可能受笔记本合盖策略影响。
